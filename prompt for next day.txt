======================================================================
PROJECT
======================================================================

We are building a production-ready Health Monitoring Platform using modern React architecture.

The application is a multi-step health assessment.

Step 1
Voice Assessment

• Record voice in browser.
• User can listen to the recording.
• User clicks "Process Voice".
• Audio is sent to an existing Praat Processing API.
• API returns values such as:

- Frequency
- Intensity

These values are stored globally.

Only after successful processing can the user continue.

----------------------------------------------------

Step 2

Patient Information

Collect

- Age
- Weight
- Height
- Sex
- Date of Birth

Store globally.

----------------------------------------------------

Step 3

Bluetooth Oximeter

Connect using Web Bluetooth API.

Read

- Heart Rate
- Oxygen Saturation (SpO₂)

Store globally.

----------------------------------------------------

Step 4

Health Formula

Use

Voice Data

Patient Data

Bluetooth Data

Pass everything into a custom health formula.

Return

- Health Score
- Recommendations
- Risk Level

Business logic must stay completely separated from UI.

----------------------------------------------------

Step 5

Health Report

Generate a beautiful HTML report containing

Voice Metrics

Patient Information

Oximeter Values

Health Score

Recommendations

Risk Level
